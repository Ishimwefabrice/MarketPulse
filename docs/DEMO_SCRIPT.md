# MarketPulse — 3-minute demo script

Target length: **2:00–2:45**. Record screen + voice. Upload to YouTube (public).

## Shot list

### 0:00–0:20 — Hook
- Full-bleed homepage: **MarketPulse** brand hero
- Line: “Weekly intel for small businesses — competitors, prices, content, actions.”
- Mention track: Best Apps and Agents; Nebius Token Factory + NVIDIA Nemotron + Tavily

### 0:20–0:50 — Onboard
- Fill form for a real niche (or use Ikawa House / Kigali café)
- Goals: traffic + pricing + content
- Create business → land on business page

### 0:50–1:40 — Run intel (live if credits allow)
- Click **Run weekly intel**
- Narrate pipeline on screen status: plan queries → Tavily search → Nemotron extract → brief
- If credits are tight: cut to pre-run brief or seed demo, but say “same pipeline” and show `.env` / README mentioning Token Factory model IDs

### 1:40–2:30 — Walk the brief
- Summary
- Competitors with **source links**
- Price signals
- One content draft
- Action list (high priority)
- Scroll **All sources** — stress Tavily is core, not bolted on

### 2:30–2:45 — Close
- “Built on Nebius Token Factory with NVIDIA Nemotron; research via Tavily.”
- Repo link + call to try the Kigali demo

## B-roll / cutaways (optional)
- README table showing Nemotron Lightning vs Super
- Token Factory dashboard (no secrets)
- Discord / hackathon page (1s)

## Do not
- Show API keys
- Spend more than 3 minutes
- Demo Physical AI / unrelated features
